## The never-assume list for agent work

- **A YAML parse is not proof of registration** — [[CLD-C001_description-hazard-chars-break-frontmatter-parsing|CLD-C001]]. Check the harness registry.
- **Permission mode does not contain a workflow** — [[CLD-C003_workflow-subagents-always-acceptedits|CLD-C003]]. Hooks do.
- **A fork cannot be tier-pinned** — [[CLD-C005_forks-always-inherit-driver-model|CLD-C005]]. Policy is the only control.
- **One env var voids the whole tier matrix** — [[CLD-C008_subagent-model-envvar-overrides-all-pins|CLD-C008]].
- **A plugin agent's `permissionMode`/`mcpServers` do nothing** — [[CLD-C009_plugin-subagents-ignore-permission-hooks-mcp|CLD-C009]]. Scope with `tools`; enforce with plugin-level hooks.
- **Auto mode does not gate machine state** — [[CLD-C011_auto-mode-classifier-does-not-gate-machine-state|CLD-C011]]. Only `ask` rules + PreToolUse hooks do; config changes go live at the NEXT session start.
- **A resumed workflow re-runs everything after the first cache hole** — [[CLD-C012_workflow-resume-prefix-replay|CLD-C012]]. Human gates go INTO the script before launch; an errored agent is a permanent hole; price the tail before any resume.
- **A `Write()`/`MultiEdit()`/`NotebookEdit()`/`Glob()` path permission rule does nothing** — [[CLD-C013_file-permission-rules-only-edit-and-read|CLD-C013]]. Only `Edit(path)`/`Read(path)` gate; use `Edit()` (covers all edit tools) or a PreToolUse hook.
- **A `file_path`-only hook misses NotebookEdit** — [[CLD-C014_notebookedit-input-key-is-notebook-path|CLD-C014]]. NotebookEdit's key is `notebook_path`; extract it too, and test a gate with every matched tool's real `tool_input` shape.
- **Auto-memory does not isolate per project inside one repo** — [[CLD-C016_auto-memory-keys-one-store-per-repo-root|CLD-C016]]. One store per repo root; redirect per-project stores ([[CLD-CAP003_automemorydirectory-redirects-store-from-subdir|CLD-CAP003]]) or the shared index bloats to the load cap.
- **A plugin agent's bare name never resolves** — [[CLD-C017_plugin-agenttypes-register-namespace-qualified|CLD-C017]]. Spawn as `<plugin>:<agent>`; mid-session installs register next session; definition-scanning gates must resolve installed plugins.
- **An `ask` rule is only as good as its answerer** - [[CLD-C019_ask-rules-fail-closed-without-an-answerer|CLD-C019]]. Interactively it prompts the owner even for subagent calls; headless / CI / scheduled runs have no answerer, so the same rule fails closed. Validate a permission scheme in BOTH modes.
- **A PreToolUse hook does not exist inside a subagent** — [[CLD-C018_pretooluse-hooks-never-run-for-subagent-calls|CLD-C018]]. Permissions and PostToolUse still apply; express protected-path Change Control as `Edit(path)` rules ([[CLD-C013_file-permission-rules-only-edit-and-read|CLD-C013]]) and strip write tools from agents that do not need them.
- **A synced-folder skill edit does not reach claude.ai** - [[CLD-C021_kb-edits-do-not-propagate-to-claude-ai-skills|CLD-C021]]. claude.ai skills refresh ONLY by manual owner upload, so a folder version bump records that a fix is *available*, not that it is in force; the same edit is simultaneously live in Claude Code for the 12 symlinked skills and inert for the 9 forked ones. Never cite a synced folder version as evidence of claude.ai behaviour, and end any synced folder-skill session with an explicit re-upload list.

- **The Bash tool's `grep` is not `/usr/bin/grep`** - [[CLD-C020_bash-tool-grep-is-a-ugrep-shim|CLD-C020]]. A shell-snapshot function reroutes it to a bundled ugrep with `-G --ignore-files` injected; some `-E` patterns silently fail and recursive sweeps under-report (7 of 10 measured). Hooks are unaffected, so an in-tool test of a hook regex is not a test of that hook. Use `/usr/bin/grep` for anything load-bearing.
- **An output style cannot configure anything** - [[CLD-C022_output-style-frontmatter-ignores-unknown-keys|CLD-C022]]. Frontmatter honours `name`, `description`, `keep-coding-instructions` and `force-for-plugin` only; every other key is dropped with no error and reads as configuration indefinitely. Behaviour and display config belong in a settings file, verified by reading back the effective key and its override chain.
- **A project-scoped plugin install is neither scoped nor reversible by default** - [[CLD-C023_plugin-project-scope-writes-three-artifacts|CLD-C023]]. It writes three artifacts, resolves "project" to the GIT TOPLEVEL rather than the working directory, and creates a repo-root `.claude/settings.json` the harness describes as "shared with your team". `marketplace remove` leaves the cache standing, and `enabledPlugins` under-reports what is live. Baseline on five axes before installing; uninstall first, deregister second, delete the cache by hand.
- **De-indexing a memory does not disable it** - [[CLD-C024_unindexed-memory-files-are-still-recallable|CLD-C024]]. A second, on-demand path enumerates the store DIRECTORY and excludes only `MEMORY.md` itself, ranking every other `*.md` on its own `description:` frontmatter. So a stale or policy-contradicting memory file is surfaceable into a live turn with nothing pointing at it, which makes deletion the correct disposal and de-indexing the wrong one. The inverse also holds: relocating pointers out of the index does not orphan their files, so an index-budget fix costs presence, not reach.
- **Adding `memory:` to an agent silently gives it write tools** - [[CLD-C025_subagent-memory-field-auto-enables-write-tools|CLD-C025]]. Read, Write and Edit are auto-enabled regardless of the declared `tools:` list, so any least-privilege tiering built on frontmatter is widened invisibly, and [[CLD-C001_description-hazard-chars-break-frontmatter-parsing|CLD-C001]] means a YAML parse cannot detect it. Declare it only on tiers where write is already sanctioned, and verify against the harness registry.
- **A project key cannot be decoded back to a path** - [[CLD-C026_project-key-encoding-is-lossy-and-not-invertible|CLD-C026]]. The encoder maps `/`, `_`, space and `.` all to a single `-`, so the encoding is lossy and its inverse is ambiguous. Substituting `/` for every `-` names a path that does not exist, which reads as evidence of an orphaned store: that exact mistake produced a recorded defect row and a remediation item proposing disposal of live content, both withdrawn 2026-09-02. Resolve a key by walking the filesystem and trying each joiner per token, pruning on prefix rather than existence, with a literal comparison rather than a glob.
- **On-demand memory recall is switched OFF unless a server flag says otherwise** - [[CLD-C027_on-demand-memory-recall-is-remotely-feature-gated|CLD-C027]]. `startRelevantMemoryPrefetch` returns before doing any work unless `tengu_moth_copse` is true or `CLAUDE_MEMORY_STORES` is set, and every local override entry point is an inert no-op. Measured false and unset 2026-09-02, so the always-on `MEMORY.md` load is the ONLY automatic surfacing channel and [[CLD-C024_unindexed-memory-files-are-still-recallable|CLD-C024]] describes a mechanism that is not currently running. Read the gate before designing against recall or scoring any experiment about it.
- **Project-key resolution is not single-valued** - [[CLD-C028_project-key-resolution-is-not-single-valued|CLD-C028]]. Three resolvers coexist and disagree: `FF` honours `CLAUDE_CODE_PROJECT_DIR_NAME` unconditionally, bare `KV` ignores it and is selected whenever `CLAUDE_CODE_REMOTE_MEMORY_DIR` is set, and `ONe` honours it only when `CLAUDE_CONFIG_DIR` is set too. The harness ships `qRr(e)`, which returns the derived key only when it differs from the effective key, so the divergence is conceded in the implementation. Never compute a key once and treat it as authoritative, and never decode one by substitution; enumerate with a separator-frontier search and make every instrument name the resolver it used.
- **A hook's `ask` on unparseable shell can pass silently in auto mode** - [[CLD-C029_hook-ask-on-unparseable-bash-can-pass-without-prompt|CLD-C029]]. Two heredoc `python3` commands drew a tripwire `ask`, no prompt reached the owner, and both ran, while every probe sent one call at a time prompted. Make protected writes through Edit or Write, back governance paths with `Edit(path)` ask rules, and treat the Bash tripwire as detection rather than a checkpoint.
